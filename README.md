# Skyglow-eVscope
The Skyglow eVscope Processing Pipeline is a specialized Python tool designed for handling, calibrating, and analyzing astrophotography raw data generated by Unistellar eVscope telescopes.  When shooting celestial objects—especially under light-polluted urban skies (skyglow)—raw FITS images contain sensor artifacts, thermal noise, and Bayer pattern color matrices that require preprocessing before high-level photometry or visual stacking can occur. This repository provides a modular, automated workflow to convert raw image sequences into calibrated, channel-split astronomical data ready for analysis.  

Key Features:
- Dark Frame Calibration: Automatically subtracts thermal noise and hot pixels using dark frames.
- Bayer Channel Extraction: Splits raw single-chip 2D sensor arrays into distinct Red, Green, and Blue sub-images for targeted photometric analysis.
- Automated Source Detection: Employs photutils (DAOStarFinder) to identify stars and measure background statistics on calibrated frames.
- Dual Execution Modes: Flexible usage via standalone modular Python scripts for batch execution or an interactive Jupyter Notebook for visual exploratory analysis.
